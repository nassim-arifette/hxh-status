# Security Policy

## Supported Versions

We support the latest version deployed on the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in this project (including automation scripts, API endpoints, push notification delivery, or credentials/secrets handling), please report it responsibly.

Do **not** report security vulnerabilities through public GitHub issues or discussions.

Instead, please use GitHub Private Vulnerability Reporting on this repository if available, or contact the maintainer directly via GitHub profile.

When reporting, please include:
- A description of the issue and its potential impact.
- Step-by-step instructions or proof-of-concept to reproduce the behavior.
- Any suggested fixes or mitigations.

We will review reports promptly, address valid issues, and credit reporters appropriately.
